This respository contains .qmd template files, data files, and image files for students to use when completing assignments in Villanova's STAT 4380 course.

Example: students should use a copy of lab_01.qmd to type their answers to Lab 01, which has instructions available at https://kgfitzgerald.github.io/NOVA_STAT_4380/labs/lab-01-hello-r.html

Links are provided to students via Brightspace and are also available on the public-facing course website: https://nova-stat-4380.netlify.app/schedule/
